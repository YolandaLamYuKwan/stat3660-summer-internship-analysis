# Source inventory

The data were collected as **GitHub JSON feeds**, filtered and normalised,
then converted to **CSV** for SAS analysis. All tables below use the 537
rows in the committed CSV, each assigned once by Source_Repository.

| File | Contents | Rows excluding header |
|---|---|---:|
| DATA_SOURCES.txt | Feed URLs, formats, conversion to CSV, counts and referenced listing hosts | n/a |
| intern_data.csv | Snapshot of data/intern_data.csv; the same input records | 537 |
| source_records.csv | Per-row recorded repository, listing URL, provider, feed URL and formats | 537 |
| website_counts.csv | HK Career Watch: 472 (87.90%); Workopia: 65 (12.10%) | 2 |
| format_counts.csv | GitHub JSON feed: 537 (100%); converted to CSV | 1 |
| linked_hosts.csv | Referenced Source_URL hosts; not directly scraped websites | 79 |
| feed_counts.csv | Feed endpoints that contributed retained rows | 2 |

The five audit CSV tables were generated by [source_pies.sas](../sas/source_pies.sas)
and verified in SAS OnDemand on 2026-10-31. Share columns are numeric
fractions (for example, 0.8790 represents 87.90%).

The original input stays at data/intern_data.csv so existing code continues
to run. The snapshot in this folder must not be appended as new data.
The TXT generator is [build_source_inventory.ps1](../scripts/build_source_inventory.ps1).

The pie-chart code is in the repository's sas/ folder. Running it writes
the source tables, a TXT, two PNGs and an HTML report to source/ on the
SAS server, and displays the two pie charts in SAS Studio RESULTS.
SAS binary datasets are kept on the SAS server; their portable table
contents are committed here as CSV.
