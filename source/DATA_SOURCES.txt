4. ATTRIBUTION AND LIMITATIONS
Each retained row is assigned once using Source_Repository, not the Source_URL domain.
Counts are after the collector keeps the first company/title/location/year record.
HK Career Watch can itself reference Workopia. Those rows count under HK Career Watch when that repository is the recorded import source.
Do not add the Data_Source Workopia count to the repository-level Workopia count.
Source_URL points to a referenced listing. It does not prove this project directly downloaded or scraped that page.
The feeds may have used HTML, APIs or other methods upstream; this project cannot infer those original formats from a URL.
Do not classify a referenced job page as an imported HTML, Excel, PDF or raw-file record.
This audit counts CSV rows. It does not claim every row is a unique vacancy or every source claim was independently verified.
The 472 rows attributed to HK Career Watch are not the same denominator as the 472 records retained by the separate core-chart deduplication.
